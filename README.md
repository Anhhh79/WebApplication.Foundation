\# WebApplication.Foundation



Project nền tảng để học và thực hành quá trình xây dựng một hệ thống ASP.NET Core Web API từ nền tảng đến kiến trúc thực tế.



\## Mục tiêu học tập



\- C# và OOP

\- Git và quy trình quản lý source code

\- HTTP và REST API

\- ASP.NET Core Web API

\- SQL Server

\- Entity Framework Core

\- Authentication và Authorization

\- Testing

\- Debugging

\- Clean Architecture khi bài toán thực sự cần



\## Công nghệ



\- .NET 10

\- ASP.NET Core

\- SQL Server 2025

\- Entity Framework Core

\- Git



\## Nguyên tắc



Ưu tiên hiểu bản chất và xây dựng hệ thống từng bước trước khi áp dụng abstraction hoặc kiến trúc nâng cao.
